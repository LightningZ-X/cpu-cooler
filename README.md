# CoolerGuide · 散热器选择指南

为 Intel 台式机提供 CPU 散热器兼容性检查与选型建议。原生 HTML、CSS、JavaScript，无第三方运行依赖。

## 本地运行

直接双击 `index.html` 即可使用，保留同目录的 `js`、`css`、`assets` 文件夹。评测资料库也可以直接打开，不需要启动服务器或安装 Node.js。

只想保留一个文件时，打开 `dist/散热器选择指南.html`：产品数据、评测资料、图片、样式、脚本和开场视频全部内嵌，选型页与资料库在同一文件中切换。网站页脚提供该文件的下载入口。查看外部官方出处与视频仍需要联网。

源码开发需要 Node.js 22 或更新版本，在项目目录运行：

```sh
npm start
```

访问 http://127.0.0.1:4173 。`npm start` 会先重新构建；`npm run build` 单独生成普通脚本和单文件离线版；`npm test` 构建并运行检查。无需安装第三方依赖。`start-local.cmd` 作为后台 HTTP 预览的备用入口保留。

```sh
npm test
```

## 功能

- Intel LGA1700 / LGA1851，收录 25 款 CPU、40 款主板、36 款散热器；其他主板支持手动输入。
- 检查 CPU/主板插槽、扣具、风冷高度、内存净空、风扇抬高、水冷安装位和总厚度。
- 主板逐型号安装组合未获得依据时保持待确认，已知冲突明确显示。
- 用途、功耗设置、维护偏好排序；不将规则排序当成温度或噪声测试。
- 用户输入实际报价后按预算筛选，未知报价不当作免费。
- 最多三款对比、本地保存、配置链接分享、移动端布局。

## 数据与适用边界

`reviews.html` 提供 51972 评测资料库，可按标题、BV 号、年份与类别筛选。数据文件位于 `data/reviews/`，原始出处与核查范围见 `docs/51972-research.md`。

当前取得最新 50 / 214 条公开投稿目录，并补充较早原视频索引。已核对 21 条 51972 图表温度与 2 条 GamersNexus 风冷/水冷同噪温差，保存在 `benchmarks.json`；保留原始出处、CPU、功耗、风扇模式、温度口径和未知条件。只有选定组与 CPU、设置功耗、持续负载用途对应时才参考同组已参测型号，不跨组拼总榜。

`python tools/collect-51972.py` 可手动刷新公开目录。遇到访问限制时停止并保存部分进度，不使用账号凭据或下载视频。目录分类按标题关键词初筛，需要人工检查；目录采集完成也不等于视频核查完成。

`data/catalog.json` 保存官方规格与来源，基础核对日期为 2026-11-14，最近补充为 2026-11-16；新增型号保留单独核对日期。价格未采集；已取得官网图片的型号标注图片来源，其余使用明确标注的类型示意图。

当前收录 21 条主板和散热器逐型号安装记录，涵盖 VRM、M.2 干涉与方向限制；不等于对所有组合提供完整安装兼容保证。主板 CPU 支持列表、BIOS、扣具版本及安装手册仍需核对。风冷限高、内存高度及水冷空间由用户提供。

`overrides` 用于后续补充有证据的主板组合结论，条目格式：

```json
{
  "board": "主板 ID",
  "cooler": "散热器 ID",
  "state": "pass 或 conditional 或 fail",
  "detail": "适配结论及适用条件",
  "source": "官方依据 URL",
  "checkedAt": "YYYY-MM-DD"
}
```

不能仅凭没有冲突记录标记通过。扩展 AMD 时添加平台数据及扣具规则，并补充相应兼容性测试。

## GitHub Pages

1. 将仓库推送到 GitHub 的 `main` 分支。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. Actions 中运行 **Verify and deploy Pages**。

工作流先执行规则测试，再上传必要静态文件并部署；使用相对路径，兼容 `用户名.github.io/仓库名/`。私有仓库的 Pages 可用性及访问范围取决于 GitHub 套餐与设置。

目录说明：`css` 样式，`js` 交互及规则，`data` 产品数据，`assets` 本地 SVG 示意图，`tests` 边界测试，`tools` 本地预览服务器。

## 界面与动效

参考同账号电源功耗计算器，采用深灰 / 红色强调、小圆角与细分隔线。支持深浅主题、原版 LIGHTNING 开场、手动重播 / 跳过，以及面板、弹窗和按钮反馈。首次访问、分享锚点和减少动态效果设置分别处理，详见 `docs/ui-style.md`。

27款对应官方产品图转换为本地WebP，保留原图/型号页出处；CQ125和Dark Rock Pro 5暂用明确标注的示意图。卡片图片可放大。新增22款风冷热管根数、4款有据的热管/鳍片连接方式和14款厂商标称TDP/D-TDP。官方仅写Soldered时标记焊接，不推断具体回流工序；未证实的型号保持未知。详情将底座结构、鳍片连接、厂商标称W与已录入实测负载分开，NSPR/Q-Max不作为整机瓦数。标称瓦数不参与推荐分数或兼容判断。证据见`docs/product-images.md`和`docs/cooler-construction-research.md`。

## v1.7.1 输入与搜索修复

型号搜索支持常见空格、连字符和全角写法；尺寸支持小数毫米。无效输入会显示错误并保留上次有效建议。切离手动功耗模式后，隐藏字段不再参与校验或阻止提交。60项测试及浏览器交互回归通过。

## v1.8.0 计算器式选型流程

参考同账号电源计算器，新增快速/完整模式、固定候选摘要和当前筛选统计；横评按需展开，冲突方案可显示原因，对比栏可查看与移除具体型号。快速模式保留已有安装数据，未知项仍待确认。

## v1.8.1 动效补齐

顶栏“动态效果”可选择跟随系统、完整动效或减少动效。新增滚动入场、配置区展开收起、按钮回弹、结果指标反馈及对比栏弹出；保留系统偏好、手机触控和打印支持。

## v1.9.0 型号与传热条件

新增7款散热器、8款Intel主板，总计25款CPU、36款散热器、40款主板。规格依据见 docs/catalog-expansion-v1.9.md；未知安装组合仍需核对。

CPU工况现在区分主板默认、Intel默认限制、手动限功耗、解除功耗限制、手动超频和降压优化。可展开“CPU体质与导热介质”填写同用途下实测持续功耗；结果区显示采用的负载依据及材料核对事项。体质/介质不换算固定温差或提高标称解热瓦数，详细规则见 docs/thermal-context.md。

## v1.11.0 选型流程优化

新增“下一步核对”入口，按插槽冲突、介质与安装空间等缺项给出最多三条可点击提示，并自动展开对应字段。填完参数仍不代表组合已验证兼容。

结果支持推荐顺序、已填报价、已知风冷安装高度排序，未知值置后，明确冲突仍排在候选之后。搜索、类型、排序、冲突显示及最多三款对比在当前浏览器恢复；分享链接不套用旧搜索筛选。一键清除结果筛选保留配置、预算和对比。
