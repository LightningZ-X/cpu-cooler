# 界面与动效参考

2026-11-14，用户明确指定参考其电源功耗计算器 https://lightningz-x.github.io/ 的 UI、风格和动效。当前线上参考与本地 `D:/deepseekharness/psu-calculator` 样式、原始视频一致。

采用深灰背景、黑色导航、少量红色强调、2px小圆角、细分隔线、紧凑双栏；资料库共用主题。两页支持深浅主题并在同源保存，首次绘制前恢复主题。

LIGHTNING 图标、字标及4.1秒视频从用户已有网站 assets 逐字节复制，无重绘；该站 lightning-source.md 记录它们为用户此前提供的原始素材。原站与所有文件保持原样。

开场只对无锚点的首页首次普通访问自动播放；分享/锚点、noanim=1、减少动态效果时跳过自动播放。可手动重播。支持跳过按钮、Esc、播放错误、自动开场 7 秒和手动重播 30 秒兜底、页面隐藏与打印时释放交互；不隐藏业务页面作为无JS后备。

组件采用150ms按压、340/220ms原生details展开收起、240ms弹窗进入、220ms结果数量变化反馈、460ms页面区域错峰进入。减少动态效果时取消非必要动画；手动播放开场仍可由用户选择。

不修改兼容判断和实测排序规则。

## v1.8.0 选型流程（2026-11-16）

再次核对同账号电源计算器在线DOM与本地源文件 `D:/开发项目/deepseekharness/psu-calculator`，借鉴其快速/完整模式、固定答案摘要和渐进展开。原站不修改。

- 快速选型保留CPU、用途、功耗和预算；完整模式展开主板与机箱/内存/水冷空间。切换只改变展示，已填安装参数仍计算。提示未填项待确认，模式在浏览器保留。隐藏安装参数无效时自动回到完整模式以便修正。
- 固定工具栏展示全部配置的候选/冲突数量，可跳到结果。结果的三个数量随当前型号、类型及预算筛选；其中待确认是候选子集，不代表认证通过。
- 横评长表默认收起，用户可原生展开；原先选定且与配置对应的测试组仍按既有规则参与排序，折叠不改变计算。
- 安装冲突默认不出现在候选卡片中，但计数、空态与开关允许查看精确冲突原因。不改兼容状态，不将冲突计入候选。
- 固定对比栏显示已选型号、单项移除和不足两款的提示；移除同步卡片，清空后释放底部空间。最多三款规则保持。
- 用户变更结果后前四张卡片轻微进入；沿用240ms、25ms错峰。减少动态效果或页面隐藏时不执行非必要动画。

## v1.8.1 动效补齐（2026-11-16）

- 顶栏新增动态效果选项：跟随系统（默认）、完整动效、减少动效；同源保存偏好。完整动效允许用户主动覆盖系统减少动态效果，减少动效取消正在进行的动画并收尾展开状态。
- 卡片按进入视口错峰出现，筛选后重新观察新卡片，移除旧观察对象；资料库视频和测试组同样支持。内容不依赖动画可见。
- 快速/完整配置以360/240ms高度和透明度过渡，收起期间禁用字段焦点，结束恢复原样；连续切换、后台、打印和减少动效时收尾。
- 按钮按压后320ms回弹；卡片图片轻微抬升、箭头方向反馈、主题颜色过渡。结果摘要和指标只在内容变化时播放反馈。
- 对比栏和提示弹出时保留原有定位变换，避免固定栏失去水平居中。手机端取消悬停动效，打印不保留过渡。

## v1.10.0 本地直开与单文件离线版

- 项目入口改用可直接从file协议加载的普通defer脚本，产品与评测数据预加载，不依赖浏览器fetch读取本地JSON。源码模块保留用于维护和测试，tools/build.mjs生成js/generated/下的运行文件。
- dist/散热器选择指南.html内嵌双页DOM、全量当前数据、全部图片与原始开场视频，约3.24MiB。资料库、返回选型和动态弹窗内的站内链接映射到本文件的view参数；外部来源链接保留。
- file协议下分享生成线上配置链接，不把不可访问的本机磁盘路径发给别人；历史操作受限时不阻断选型。
- Canvas播放器沿用电源计算器的视频等比绘制方式，原始视频SHA256仍为3C3F5957F67100B00ED40DB76CCFB34752ACA01596D072F6366DADA49CE0C411。支持视口变化、结束、错误、跳过、Esc、超时、后台和打印的清理；减少动效仍跳过自动开场，可手动重播。退出开场后当前视口的页面区域错峰进入。
- 构建不安装外部依赖。只支持本项目当前的本地命名导入/声明导出语法；循环依赖、动态导入及未支持语法使构建失败，不悄悄生成残缺产物。CI测试先构建，Pages同时发布dist下载文件。

## v1.11.0 流程优化（2026-11-16）

- “下一步核对”以实际配置和当前散热类型生成提示，优先处理插槽冲突和未安装导热介质。点击提示先打开嵌套details，再展开完整配置、滚动与聚焦；不把填写完整当成已验证安装。
- 结果排序支持已填报价和已知风冷安装高度。价格未知、高度未知和水冷不当作零值；冲突仍排在候选后。高度说明保留内存、风扇抬升和公差限制，不改变推荐计算或温度口径。
- 结果筛选和对比型号另存于coolerguide-view-v1，恢复前验证枚举、型号存在性、去重及最多3款；分享配置不套用旧搜索/类型/排序，避免打开链接后无故看不到型号。
- 清除结果筛选保留配置、预算和已选对比；完全重置仍使用原有重置入口。推荐顺序下优先标记当前可见首个候选，其他排序不显示推荐标记。
- 未知主板设置但已有实测持续功耗时，说明与实际采用的功耗保持一致。屏幕阅读器只播报结果数量变化，不重读整个卡片列表。

## Remotion 高清开场与光标渐变

当前开场在 `remotion/src/index.jsx` 直接使用 `assets/lightningz-gap-cut-v2.mp4` 原片及音轨。逐帧轻度平滑压缩噪点、增强局部边缘，并把红色调为闪电黄。约 4.1 秒的 2560×1440、30 fps 成品位于 `assets/lightningz-gap-cut-gold.mp4`，细节受 1280×720 源片限制。首页原生视频静音播放该成品逐帧超分后输出的 3840×2160 版本（`assets/lightningz-gap-cut-gold-sr-4k.mp4`），单文件离线版内嵌同一份 4K 视频。可用 `?intro=1` 重播，或点击顶栏的「重播开场」。

在项目根目录运行以下命令可安装 Remotion 依赖、打开时间线或重新构建视频。重新渲染完成后执行 `npm run build` 更新离线单文件。

```sh
npm --prefix remotion ci
npm --prefix remotion run studio
npm --prefix remotion run render
```

诊断栏、散热器卡片和资料库区块的黄色渐变按鼠标或笔的实际坐标更新。选择「跟随系统」时保留这个局部颜色反馈，选择「减少动效」时关闭。
