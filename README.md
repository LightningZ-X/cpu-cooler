# CoolerGuide · 散热器选择指南

为 Intel 与 AMD AM5 台式机提供 CPU 散热器兼容性检查与选型建议。原生 HTML、CSS、JavaScript，无第三方运行依赖。

## 本地运行

直接双击 `index.html` 即可使用，保留同目录的 `js`、`css`、`assets` 文件夹。评测资料库也可以直接打开，不需要启动服务器或安装 Node.js。

只想保留一个文件时，打开 `dist/散热器选择指南.html`：产品数据、评测资料、图片（内容池去重后 4.09 MiB）、样式、脚本和开场视频全部内嵌，选型页与资料库在同一文件中切换并支持实测条件跨页一键联动。网站页脚提供该文件的下载入口。查看外部官方出处与视频仍需要联网。

源码开发需要 Node.js 22 或更新版本，在项目目录运行：

```sh
npm start
```

访问 http://127.0.0.1:4173 。`npm start` 会先重新构建；`npm run build` 单独生成普通脚本和单文件离线版；`npm test` 构建并运行检查。无需安装第三方依赖。`start-local.cmd` 作为后台 HTTP 预览的备用入口保留。

```sh
npm test
```

## 功能

- Intel LGA1700 / LGA1851 与 AMD AM5 桌面平台。收录 51 款 CPU、54 款主板、43 款散热器，其中 AM5 有 26 款 CPU、14 款主板。其他主板支持手动输入。
- AMD 温控按 CPU 型号显示 Tjmax、参考 PPT 和芯片布局。可填写实测 Tctl/Tdie 与持续封装功耗，核对底座接触和有来源的偏移安装方案。
- 检查 CPU/主板插槽、扣具、风冷高度、内存净空、风扇抬高、水冷安装位和总厚度；区分「尺寸与插槽匹配」绿标与逐板官宣兼容记录。
- 主板逐型号安装组合未获得依据时保持待确认，已知冲突明确显示。
- 用途、功耗设置、维护偏好排序；支持开箱即用的日常参考价区间预算筛选与参考均价排序，也可用到手报价精确覆盖。
- 紧凑首屏诊断条与双列/列表视图切换、机箱/内存/预算一键预设、最多三款对比（含内存净空/避让、平台与 AM5 偏移、当前同条件实测最优高亮及仅看差异行）、本地保存、配置链接分享、移动端布局。

## 数据与适用边界

`reviews.html` 提供评测资料库，支持按平台与兼容结论筛选 64 条主板逐板安装记录、按插槽分组浏览实测组并一键带入选型页，也可按标题、BV 号、年份与类别筛选 51972 视频目录。数据文件位于 `data/reviews/`，原始出处与核查范围见 `docs/51972-research.md`。

当前取得最新 50 / 214 条公开投稿目录，并补充较早原视频索引。已核对 21 条 51972 图表温度与 16 条 GamersNexus 同噪温差（覆盖 Intel 14900KF 与 AMD AM5 9800X3D / 9950X3D），保存在 `benchmarks.json`；保留原始出处、CPU、功耗、风扇模式、温度口径和未知条件。只有选定组与 CPU、设置功耗、持续负载用途对应时才参考同组已参测型号，不跨组拼总榜。

`python tools/collect-51972.py` 可手动刷新公开目录。遇到访问限制时停止并保存部分进度，不使用账号凭据或下载视频。目录分类按标题关键词初筛，需要人工检查；目录采集完成也不等于视频核查完成。

`data/catalog.json` 保存官方规格与来源，基础核对日期为 2026-11-14，最近补充与参考价整理为 2026-11-20。新增型号保留单独核对日期。已取得 41 款官网产品图并标注来源，其余 2 款（CQ125、Dark Rock Pro 5）使用明确标注的类型示意图。

当前收录 64 条主板和散热器逐型号安装记录，涵盖 VRM、M.2 干涉、ITX 主板边缘和方向限制以及 ARCTIC 官方 AM5 逐板兼容确认。主板 CPU 支持列表、BIOS、扣具版本及安装手册仍需核对。风冷限高、内存高度及水冷空间由用户提供。

`overrides` 用于后续补充有证据的主板组合结论，条目格式：

```json
{
  "board": "主板 ID",
  "cooler": "散热器 ID",
  "state": "pass 或 conditional 或 fail",
  "detail": "适配结论及适用条件",
  "source": "官方依据 URL",
  "checkedAt": "YYYY-MM-DD"
}
```

缺少逐组合安装记录时保留待核对状态。温控依据和盈余计算见 `docs/thermal-context.md`。

## GitHub Pages

1. 将仓库推送到 GitHub 的 `main` 分支。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. Actions 中运行 **Verify and deploy Pages**。

工作流先执行规则测试，再上传必要静态文件并部署；使用相对路径，兼容 `用户名.github.io/仓库名/`。私有仓库的 Pages 可用性及访问范围取决于 GitHub 套餐与设置。

目录说明：`css` 样式，`js` 交互及规则，`data` 产品数据，`assets` 本地 SVG 示意图，`tests` 边界测试，`tools` 本地预览服务器。

## v1.11.0 选型流程优化

新增“下一步核对”入口，按插槽冲突、介质与安装空间等缺项给出最多三条可点击提示，并自动展开对应字段。填完参数仍不代表组合已验证兼容。

结果支持推荐顺序、已填报价、已知风冷安装高度排序，未知值置后，明确冲突仍排在候选之后。搜索、类型、排序、冲突显示及最多三款对比在当前浏览器恢复；分享链接不套用旧搜索筛选。一键清除结果筛选保留配置、预算和对比。
